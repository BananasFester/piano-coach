Add a song

Write each note as a letter and octave: C4 is middle C, F#4 is F sharp, Bb3 is B flat. Each note is one beat. Add :2 to hold for two beats or :0.5 for half a beat. Use R for a rest.

Chords build the left hand for Medium and Hard. Write a chord then :beats, like C:4 G7:4. Types: C, Cm, C7, Cm7, Cmaj7, Cdim, Csus4, C6, C5.
